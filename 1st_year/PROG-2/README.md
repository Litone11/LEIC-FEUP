# PROG 2 — Processador da Linguagem SCRIM (Manipulação de Imagens)

Projeto da Unidade Curricular de Programação II (PROG) da LEIC @ FEUP.

Este projeto consiste na implementação em C++ de um interpretador e processador de scripts da linguagem **SCRIM**, desenhada para aplicação de operações e transformações digitais em imagens PNG.

## 🛠️ Funcionalidades e Arquitetura

- **Linguagem:** C++ (C++17, CMake)
- **Componentes:**
  - `ScrimParser`: Parsing de comandos de edição de imagem em ficheiros `.scrim`.
  - Operações de Imagem: Filtros, transformações de cor, composição de pixéis.
  - Leitura e Escrita de Imagens PNG.
