# DA 2 — Algoritmos de Otimização (Problema da Mochila / 0-1 Knapsack)

Projeto 2 da Unidade Curricular de Desenho de Algoritmos (DA) da LEIC @ FEUP.

Este projeto foca na resolução e análise comparativa de eficiências para o **Problema da Mochila 0/1 (0-1 Knapsack Problem)** no contexto de carregamento otimizado de paletes e rotas marítimas.

## 🛠️ Tecnologias e Algoritmos

- **Linguagem:** C++ (C++17)
- **Abordagens Algorítmicas:**
  - Força Bruta (*Brute-Force Search*)
  - Programação Dinâmica (*Dynamic Programming*)
  - Algoritmos Gulosos (*Greedy Approximation*)
  - Programação Linear Inteira (*Integer Linear Programming - ILP*)
