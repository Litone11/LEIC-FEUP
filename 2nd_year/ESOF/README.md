## 📌 Sobre o Projeto

O **TaskMate** é uma aplicação mobile focada na organização pessoal e colaborativa de tempo e tarefas. A aplicação permite que estudantes, profissionais e equipas gira as suas atividades diárias, definam prioridades e colaborem em projetos comuns através de uma interface intuitiva e fluida.

O projeto foi desenvolvido seguindo rigorosamente a metodologia **Agile/Scrum**, englobando desde a visão do produto e user stories até ao desenvolvimento de protótipo vertical e testes.

---

## 🛠️ Tecnologias e Ferramentas

- **Frontend / Mobile:** Flutter (Dart)
- **Metodologia:** Agile / Scrum (Sprints 0 a 4)
- **Modelação & Design:** UML (Modelos de Domínio, Diagramas de Arquitetura), Figma
- **Gestão de Projeto:** GitHub Projects / Kanban, User Stories

---

## ✨ Funcionalidades Principais

- **Gestão de Tarefas:** Criação, edição, categorização, priorização e conclusão de tarefas.
- **Projetos Colaborativos:** Partilha de listas de tarefas e atribuição de responsabilidades em grupo.
- **Agendamento e Notificações:** Definição de prazos (*deadlines*) e lembretes de tarefas pendentes.
- **Dashboards de Produtividade:** Acompanhamento do progresso individual e de equipa.

---

## 📁 Arquitetura e Estrutura

- **Business Modeling & Requirements:** Visão do produto, Elevator Pitch, User Stories e Modelo de Domínio.
- **Architecture & Design:** Arquitetura Lógica e Física, Protótipo Vertical.
- **Gestão de Sprints:** Documentação do progresso ao longo dos Sprints 0, 1, 2, 3, 4 e Release Final.

---

## 🚀 Como Executar o Protótipo

1. Certificar que o SDK do Flutter está instalado na máquina.
2. Obter as dependências do projeto:
   ```bash
   flutter pub get
   ```
3. Iniciar a aplicação no emulador ou dispositivo físico:
   ```bash
   flutter run
   ```
