Detailed Description

XPM font character declarations and text drawing utility.

Provides external declarations for character XPMs (A-Z, 0-9, colon) and a utility function to render text strings on screen using these XPM-based fonts.

This module is useful for displaying HUD elements such as scores or labels in a pixel-art style.

int x,

int spacing )

Draws a string of characters using XPM pixel-art font.

Iterates through each character in the string and renders the corresponding XPM character sprite at the given (x, y) coordinates with specified spacing.

Parameters
strNull-terminated string to render (A-Z, 0-9, ':').
xX coordinate where the string starts.
yY coordinate where the string baseline is drawn.
spacingHorizontal spacing in pixels between characters.
