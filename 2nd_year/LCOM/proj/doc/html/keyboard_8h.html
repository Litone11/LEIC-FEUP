Detailed Description

Functions and definitions for handling keyboard interrupts and scancodes.

Provides declarations for subscribing/unsubscribing keyboard interrupts, enabling keyboard interrupt handling via the KBC, and interpreting scancodes.

◆ checking_scancode()

int checking_scancode ( )

Interprets the current scancode.

Determines if the current scancode is a single-byte or part of a multi-byte sequence. Stores the scancode in a buffer accordingly.

Returns
  • 2 if a two-byte scancode has been fully read,
  • 1 if a single-byte scancode has been read,
  • 0 if the first byte of a two-byte scancode has been read.
