Detailed Description

Includes all XPM image assets used in the game.

This header aggregates all XPM file inclusions into a single point of reference, allowing other modules to easily include and access all game-related image resources, such as backgrounds, ships, meteors, buttons, titles, and icons.

These images are used for rendering the visual elements of the game using the LCF graphics module.
