\doxysubsection{Detailed Description}
Handles meteor entity logic including spawning, updating, and removal. 

Declares functions and variables used to manage falling meteors on screen. Supports timed spawning, downward movement, and memory cleanup.

This module is used in gameplay to add obstacles dynamically.
