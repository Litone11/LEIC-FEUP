\doxysubsection{Detailed Description}
\doxylink{struct_x_p_m}{XPM} font character declarations and text drawing utility. 

Provides external declarations for character XPMs (A-\/Z, 0-\/9, colon) and a utility function to render text strings on screen using these XPM-\/based fonts.

This module is useful for displaying HUD elements such as scores or labels in a pixel-\/art style.
