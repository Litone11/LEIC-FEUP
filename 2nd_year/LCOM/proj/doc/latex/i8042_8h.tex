\doxysubsection{Detailed Description}
Constants for the i8042 keyboard and mouse controller. 

This header defines useful macros and constants related to\+:
\begin{DoxyItemize}
\item IRQ lines
\item KBC (Keyboard Controller) registers and status flags
\item Mouse communication commands and bit masks
\item Useful scancodes for keyboard events
\end{DoxyItemize}

These constants are used for handling keyboard and mouse input in Minix-\/based low-\/level programming.
