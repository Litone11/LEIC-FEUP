\doxysubsection{Detailed Description}
Video graphics interface using VBE and double buffering. 

Declares functions for setting video mode, mapping memory, drawing pixels, lines, rectangles, \doxylink{struct_x_p_m}{XPM} images, and swapping buffers.

Uses VBE mode information and double buffer to render graphics in Minix.
