# LTW — Plataforma Web de Serviços Freelance

Projeto da Unidade Curricular de Linguagens e Tecnologias Web (LTW) da LEIC @ FEUP.

Este projeto consiste numa aplicação web dinâmica para a contratação e prestação de serviços por freelancers, com diferentes níveis de acesso e dashboards personalizados.

## 🛠️ Tecnologias Utilizadas

- **Backend:** PHP (PDO, Sessões, Autenticação)
- **Base de Dados:** SQLite
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Funcionalidades:**
  - Autenticação e Perfis (Administrador, Cliente, Freelancer)
  - Pesquisa e Publicação de Serviços / Propostas
  - Sistema de Gestão de Contratações e Avaliações
