# IA 1 — Water Sort Puzzle Solver

Projeto desenvolvido no âmbito da Unidade Curricular de Inteligência Artificial (IA) da LEIC @ FEUP.

Este projeto consiste na resolução e otimização do jogo **Water Sort Puzzle** através da implementação de diversos algoritmos de pesquisa em inteligência artificial, contando com uma interface gráfica desenvolvida em Tkinter.

## 🚀 Algoritmos de Pesquisa Implementados

- **Pesquisa Não Informada:**
  - Pesquisa em Largura (*Breadth-First Search* - BFS)
  - Pesquisa em Profundidade (*Depth-First Search* - DFS)
  - Pesquisa de Custo Uniforme (*Uniform Cost Search* - UCS)
- **Pesquisa Informada (Heurísticas):**
  - Pesquisa $A^*$ (*A-Star*)
  - Pesquisa Gulosa (*Greedy Best-First Search*)

## 💻 Como Executar

```bash
python main.py
```
